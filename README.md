# Halloween Game Show

A one-page classroom game for Grade 5 with two modes:

- **Spooky Points**: a board of 6 categories (Monsters, Inc., kids' movies, Halloween around the world, and this week's math, reading, and writing). Every group answers each question. Right +100, wrong −100, no answer 0.
- **Pumpkin Poll**: groups take turns picking the #1 answer. #1 = 100, #2 = 75, #3 = 50, #4 = 25.

Supports 2 to 10 groups. Scores carry across both games. Runs offline: open `index.html` in any browser.
